 # Customer Behaviour Analysis

## 📌 Description

This project analyses customer shopping behaviour using Python, SQL, Excel, and Power BI.

The dataset was cleaned, analysed, and visualised to identify customer purchasing patterns.

The project provides insights into customer demographics, product performance, discounts, subscriptions, and revenue trends.

## 🔍 Key Analysis

- Compared revenue generated by male and female customers.
- Identified high-value customers who used discounts.
- Found the top 5 highest-rated products.
- Compared spending for Standard and Express shipping.
- Analysed subscriber vs. non-subscriber spending.
- Identified products most frequently purchased with discounts.
- Segmented customers into New, Returning, and Loyal groups.
- Found the top 3 products in each category.
- Analysed repeat buyers and subscription behaviour.
- Calculated revenue contribution by age group.

## 🛠️ Tools Used
